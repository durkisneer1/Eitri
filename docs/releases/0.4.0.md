# Eitri 0.4.0 — A more comfortable VHDL workspace

This release makes everyday editing and connecting components easier, with assistance that stays where you want it.

## What's new

- **Open a project from your terminal.** Use `eitri .` for the current folder or `eitri "/path/to/project"` for another directory. Running `eitri` alone still opens a blank workspace, and launching the app returns your terminal prompt immediately.
- **Indent like you would in a familiar code editor.** Tab and Shift+Tab indent or unindent selected lines. Backspace removes one indentation level when you're at a four-column stop in a line's leading whitespace.
- **Make room for your code.** The VHDL assistance panel now has a permanent place below the editor or on its right. Resize it, hide it, or bring it back with the Problems button. Eitri remembers your layout, and messages no longer make the panel appear and disappear as you type.
- **A quieter theme switch.** The sun/moon button blends into the sidebar until you hover over it. Switching between light and dark mode keeps your diagnostics and assistance panel in place.
- **A little encouragement from the forge.** When a check finishes without diagnostics, the assistance panel has a few words for the smith at the keyboard. Clear another set of issues to discover another message.

## Easier component wiring

**Insert instance…** now places the instance inside the architecture, even if your cursor is in the entity declaration or elsewhere in the file. If there are several possible architectures, Eitri lets you choose. It also avoids duplicate instance labels and selects the first connection placeholder so you can start wiring immediately.

Any code you had selected is left intact, and an inserted instance can be undone in one step. You still choose the signal connections—Eitri helps with placement and syntax, while the design remains yours.

## Getting started

```sh
python -m pip install --upgrade eitri-hdl
eitri .
```

Supports Python 3.12–3.15 on Windows x64, Linux x64, and macOS Apple Silicon. Try the [learning CPU walkthrough](https://github.com/durkisneer1/Eitri/tree/v0.4.0/examples/learning_cpu) to explore components, simulation, and circuit diagrams together.
