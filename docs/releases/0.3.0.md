# Eitri 0.3.0

## Appearance

- Add a persistent light/dark mode toggle at the bottom left of the workspace.
- Apply the selected theme to editors, diagnostics, waveforms, circuits,
  component hierarchy and individual SVG exports.
- Preserve circuit zoom and hierarchy selection when switching themes.

## Circuit generation

- Recognize exhaustive binary mux decoders independently of source names and
  render consistent mux blocks in Simple mode.
- Expand recognized muxes into bus-aware AND, OR and NOT logic in Detailed mode.
- Simplify identical mux branches and repeated bit functions, with explicit
  wire-replication symbols.
- Preserve shared decoder logic and avoid simplifying ambiguous decoders.
- Distinguish reductions and whole-bus logical tests from parallel bitwise gates.
- Prevent unused X/Z aliases from creating misleading unknown-value boxes.
- Restore descriptive captions for compiler-generated cell names containing periods.

The original synthesis netlist remains unchanged. Detailed mode retains
arithmetic and register symbols; the schematic represents synthesized binary
logic rather than nine-state VHDL simulation or a specific FPGA technology.

## Verification

The 170-test suite includes behavioral and Yosys equivalence checks across muxes,
arithmetic, shifts, reductions, extension wiring and registers, plus live-theme
and export regressions. The release workflow additionally verifies clean wheel
installations on Python 3.12–3.15 for Windows x64, Linux x64 and macOS ARM64.
