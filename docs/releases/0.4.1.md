# Eitri 0.4.1 — See your final test case

This patch fixes waveforms that appeared to stop before the requested stop time, hiding the last test case.

- **Waveforms now extend to your chosen stop time.** If the last recorded change is at 50 ns and you request 60 ns, the final values stay visible and selectable through 60 ns.
- **The final time label stays visible.** The ruler no longer clips its rightmost label outside the waveform view.
- **Clearer simulation status.** When the preview carries final values beyond the last recorded timestamp, Eitri tells you. Original waveform exports remain unchanged; the extended preview does not imply the simulator continued past an explicit early stop.

Restart Eitri and rerun your simulation after updating:

```sh
python -m pip install --upgrade eitri-hdl
```
